# Hamada Shop — ملفات المتجر

هذه نسخة أولية جاهزة للرفع على Cloudflare Pages. الواجهة بالعربية والفرنسية، والعملات بالدرهم المغربي، والطلب يفتح واتساب على الرقم المحدد.

## 1) قبل النشر

1. افتح `config.js`.
2. غيّر `SUPABASE_URL` إلى رابط مشروعك الحالي في Supabase.
3. ضع مفتاح `anon/public` فقط في `SUPABASE_ANON_KEY`.
4. لا تضع مطلقاً مفتاح `service_role` أو أي مفتاح سري في ملفات الموقع.
5. تأكد أن رقم واتساب هو رقمك الصحيح بصيغة دولية من دون `+` أو مسافات.

## 2) افتراضات قاعدة البيانات

الواجهة تتوقع وجود الجداول التالية وأسماء الأعمدة:

### products
- `id` (معرّف)
- `name` (نص)
- `name_fr` (نص، اختياري)
- `description` (نص، اختياري)
- `description_fr` (نص، اختياري)
- `price` (رقم)
- `category` (نص: `boys` أو `girls` أو `babies`)
- `image_url` (نص، اختياري)
- `is_active` (boolean)
- `created_at` (تاريخ)

### admin_users
- `user_id` (UUID) ويطابق UID حساب الإدارة في Supabase Auth.

هذه افتراضات وليست تأكيداً أن جداول مشروعك الحالية مطابقة. لا تشغّل أي SQL لإنشاء الجداول من جديد قبل مقارنة الأعمدة الموجودة.

## 3) لوحة الإدارة

افتح `admin.html` وسجّل الدخول ببريد وكلمة مرور حساب Supabase Auth الذي أضفته إلى `admin_users`. يجب أن تسمح سياسات RLS للمستخدم الإداري الموثّق بقراءة/إضافة/حذف المنتجات، وبالتحقق من عضويته في `admin_users`.

## 4) سياسات الأمان مهمة

- فعّل RLS على الجداول.
- اسمح للزوار بقراءة المنتجات النشطة فقط.
- اسمح بإضافة/تعديل/حذف المنتجات للمستخدم الإداري الموثّق فقط.
- اسمح للمستخدم الإداري بقراءة صفه في `admin_users` فقط.
- لا تجعل `admin_users` قابلاً للقراءة العامة.
- اختبر السياسات بحساب زائر غير مسجّل وبحساب الإدارة قبل نشر الموقع.

لا يمكنني تأكيد سياسات مشروعك الحالية من هذه الملفات؛ راجعها في Supabase قبل النشر العام.

## 5) الطلبات

زر الطلب يفتح رسالة واتساب جاهزة إلى الرقم `212766445061`. هذه النسخة لا تضيف الطلب تلقائياً إلى جدول `orders` ولا تحسب مخزوناً ولا تستقبل الدفع إلكترونياً. لا تعرض الطلب على أنه مسجّل في لوحة الإدارة.

## 6) النشر على Cloudflare Pages

ارفع محتويات هذا المجلد إلى جذر مستودع GitHub المرتبط بمشروع Pages، ثم انتظر اكتمال النشر. إعدادات مشروع HTML ثابت:
- Framework preset: `None`
- Build command: اتركه فارغاً
- Build output directory: `/` أو `.` حسب واجهة Cloudflare

بعد النشر افتح رابط الموقع على الهاتف واختبر:
1. ظهور المنتجات.
2. زر واتساب.
3. تبديل اللغة.
4. تسجيل دخول الإدارة وإضافة منتج تجريبي ثم حذفه.

## محتويات الحزمة
- `index.html`: واجهة المتجر.
- `admin.html`: لوحة الإدارة.
- `app.js` و`admin.js`: وظائف الموقع.
- `styles.css`: التصميم المتجاوب.
- `config.js`: إعدادات الاتصال.
